Bienvenido al Explorador Cósmico

Aquí tienes unos consejos para empezar:

  • Haz clic en la pantalla para activar el modo de vuelo libre.
  • Usa el ratón para mirar y las teclas W, A, S, D para moverte. Espacio para subir y Shift para bajar.
  • Apunta con la mirilla a un planeta. Mantén la vista para que la cámara lo siga automáticamente.
  • Usa los botones de la esquina inferior izquierda para mostrar ayuda (?), volver al Sol (☀️) o activar las constelaciones (✨).
  • Ajusta el volumen con el control 🔊 en la esquina inferior derecha.
  • Presiona Esc para liberar el ratón y acceder a los menús.
